# Асық Arena

Откройте `index.html` в браузере, чтобы запустить 2D-версию игры. Файл `index-3d.html` запускает модульную 3D-версию на Three.js. Откройте терминал в папке `outputs` и выполните `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000/index-3d.html`. Если проект скопирован в одну папку и `index-3d.html` лежит прямо в ней, запускайте ту же команду из этой папки. Не добавляйте `--directory outputs`, если вы уже находитесь в папке с HTML-файлом. Для аккаунтов, синхронизации прогресса, покупок и рейтингов создайте проект Supabase и введите Project URL и Publishable key в `js/supabase-client.js` для 3D-версии (а для отдельной 2D-версии — в `index.html`). В новом проекте Supabase запустите `supabase-setup.sql` в SQL Editor: скрипт создаёт нужные таблицы, политики, триггер и представления рейтинга. Файл `supabase.sql` — миграция для уже существующих таблиц. Регистрационный триггер сам создаёт профиль из метаданных пользователя.



## Публикация 3D-версии на Netlify

Для Netlify Drop подготовлена папка `netlify-3d`: её `index.html` открывает 3D-игру сразу на главной странице, а `index-2d.html` — 2D-версию. Перетащите всю папку `netlify-3d` в [Netlify Drop](https://app.netlify.com/drop), сохраняя вложенные `css/` и `js/`.

## Структура файлов 3D-версии

- `index-3d.html` — разметка и точка входа.
- `css/styles.css` — оформление интерфейса.
- `js/app.js` — состояние игры, управление, меню и модальные окна.
- `js/physics.js` — движение, столкновения и границы поля.
- `js/levels.js` — уровни и ежедневная расстановка.
- `js/scene3d.js` — Three.js-сцена, модели, камера, свет и отрисовка.
- `js/storage.js` — локальные рекорды, выбранные и купленные скины.
- `js/config.js` — общие размеры поля, физические константы и палитры.
- `js/supabase-client.js` — подключение клиента Supabase.
- `supabase-setup.sql` — полная первичная схема Supabase; `supabase.sql` — миграция существующей схемы.

В 3D-варианте поле, асыки, камера и освещение отрисованы в объёме; броски и столкновения сохраняют исходную плоскую физику.

## Правила и авторские дополнения

Потяните от любой точки поля назад и отпустите. Сақа полетит в противоположную сторону; сила броска зависит от длины натяжения. Пунктир показывает примерный путь без столкновений.

- За каждый выбитый асык начисляется 1 очко; бросок, выбивший два или больше асыков, получает ещё 1 очко за комбо.
- Одна звезда даётся за выбитые 50% цели, две — за 75%, три — за всю цель.
- Университетский рейтинг суммирует лучший результат каждого игрока на каждом уровне. Укажите вуз при регистрации, чтобы результаты попали в его вклад.
- Ежедневное испытание использует одинаковую для всех игроков расстановку в течение календарного дня по времени Алматы.
- Скины косметические. Экран магазина работает в тестовом режиме и не проводит платежи.
- Пользовательские расстановки можно собрать в редакторе и передать ссылкой.

Мультиплеер временно скрыт до исправления синхронизации очереди и индивидуальных очков.
